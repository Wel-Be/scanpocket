# ScanPocket 配置メモ
PDF取り込みには PDF.js (v3.11.174 の build 版) の次の2ファイルを lib/ に置いてください。
  lib/pdf.min.js
  lib/pdf.worker.min.js
入手先: https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.min.js
        https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.worker.min.js
(置かない場合も、写真のスキャン機能はそのまま使えます)
